# DESIGN.md library

Each `library/<brand>/DESIGN.md` holds YAML tokens (colors, typography, spacing, radii, components)
plus rules and rationale for that brand-inspired visual language.

## Use
1. Pick the brand(s) matching the requested feel from the index below. If none named, suggest 2–3 that fit.
2. Read only the chosen `library/<brand>/DESIGN.md`.
3. Apply its tokens and rules when building UI, or copy it into the project as `DESIGN.md`
   (e.g. to upload to Claude Design). Adapt — do not reproduce brand logos, names or trademarked assets;
   these are inspirations, not official brand kits.
